# Systems Perspective

## 空间、状态与自主行为

我把机器人系统理解为一个持续维护、验证和消费状态的闭环，而不是若干独立算法的简单组合。

### 三种空间

- **度量空间（Metric Space）** — 我在哪里？周围有什么？是否可通行？
- **符号空间（Symbolic Space）** — 对象是什么？它们有什么关系？任务意味着什么？
- **世界空间（World Space）** — 系统理解的世界处于什么状态？哪些信息可信、哪些动作可执行？

这三种空间是系统认知层次，不是互斥的地图算法，也不把 World Space 与 World Model 混为一谈。

### 状态契约

状态不只是数据结构，还应包含：

- 来源与时间；
- 坐标系与版本；
- 置信度与有效期；
- 生命周期和撤销语义；
- 使用权限与责任边界。

这些契约会继续延伸到任务执行、故障恢复和多智能体协同。

## 自主系统闭环

```text
Observe → Interpret → Decide → Act → Verify → Recover
```

可靠自主系统不仅要能够行动，还要知道何时不可信、如何降级、如何恢复，以及如何让外部人员验证这些判断。
