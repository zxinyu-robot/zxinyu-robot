> **From autonomous robots to governed intelligent systems.**

## 🔭 Research Vision

- **Autonomous Systems** — 管理空间状态、任务契约、行为执行与故障恢复，让自主系统可验证、可恢复。
- **Multi-Agent Coordination** — 在异构能力、局部信息与通信受限下实现协同、任务分配与风险控制。
- **Sociotechnical Governance** — 自主智能体进入公共空间与基础设施后，协作规则、责任边界与风险治理如何设计。

## 🧠 Current Research Questions

1. **状态可靠性**：自主系统如何表达、验证并管理空间状态与决策信息的可信度和生命周期？
2. **经验与自适应**：机器人如何积累可复用的行为经验，又不把过时或不适用的策略迁到新场景？
3. **韧性协同**：在局部可观测、通信受限和约束冲突下，异构智能体如何保持协同并恢复运行？
4. **智能系统与社会治理**：自主智能体进入公共环境后，协作规则、运行权限、风险与责任应如何设计？

正在探索的技术方向：语义状态 Token、ESN / 事件式时序记忆、端侧持续适应、世界模型。它们都被当作可独立验证、可替换的方法，重点是与真实机器人运行时衔接，并用可复现实验检验收益、边界和失败模式。
