## What I Build

### Reliable Autonomy

- **[quadruped-crossfloor-nav-ws](https://github.com/zxinyu-robot/quadruped-crossfloor-nav-ws)** — Go2 四足机器人跨楼层导航案例。
- **[legged-navigation-runtime](https://github.com/zxinyu-robot/legged-navigation-runtime)** — 足式导航运行时、故障恢复与诊断集成。

### Spatial Intelligence

- **[ForkSpatial-Runtime-Engine](https://github.com/zxinyu-robot/ForkSpatial-Runtime-Engine)** — 状态契约、执行租约与空间状态运行时。
- **[spatial-map-foundation](https://github.com/zxinyu-robot/spatial-map-foundation)** — 地图瓦片、空间锚定与版本化状态事务。

### Multi-Agent Systems

- **[swarm-adapter-foundation](https://github.com/zxinyu-robot/swarm-adapter-foundation)** — 多机状态、地图与指令契约，以及弱网通信和子图融合。

### Embodied Learning

- **[embodied-learning-baselines-](https://github.com/zxinyu-robot/embodied-learning-baselines-)** — 具身学习基线与交互式导航实验。

## Selected Cases

- **Case A — UAV Navigation**：无 GPS、弱网环境下的无人机自主导航，见 [uav](https://github.com/zxinyu-robot/uav)。
- **Case B — Quadruped Cross-Floor Navigation**：Go2 跨楼层自主导航闭环，见 [quadruped-crossfloor-nav-ws](https://github.com/zxinyu-robot/quadruped-crossfloor-nav-ws)。
- **Case C — Spatial Runtime**：空间状态、执行租约和智能系统交互，见 [ForkSpatial-Runtime-Engine](https://github.com/zxinyu-robot/ForkSpatial-Runtime-Engine)。

## Current Focus

- Make spatial state explicit, versioned, and recoverable.
- Build runtime semantics for reliable autonomy.
- Connect robot execution with multi-agent coordination.
- Turn real-world failures into reusable validation assets.
